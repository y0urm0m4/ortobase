# Ortobase — общая сводка

Курсовой/коляжный проект: сайт-витрина ортопедического магазина **Ortobase**.

## Цель
Демонстрационный сайт магазина, где пользователь может посмотреть каталог товаров: цена, доступные размеры, картинка, описание и 2–3 «крутых свойства» как визуальный хук.

> Это коляжный проект — упор на наглядность и опрятность, а не на продакшн-уровень: без авторизации, корзины, оплаты и админки. Просто показать товары и страницы.

## Подход (вариант А)
- Статические страницы (О нас, Почему мы, FAQ, Главная) — обычный **HTML**.
- Только **каталог** написан на **PHP**, потому что только ему нужны данные из БД.
- Так показываем препу и фронт (HTML/CSS/Bootstrap/JS), и бэк (PHP + MySQL).

## Стек
- **Фронтенд:** HTML5, CSS3, Bootstrap 5, JavaScript (vanilla)
- **Бэкенд:** PHP (только `catalog.php`, без фреймворков, чистый PDO)
- **БД:** MySQL / MariaDB
- **Сервер:** XAMPP / OpenServer (локалка под Windows)

## Страницы
1. **Главная** (`index.html`) — лендинг
2. **О нас** (`about.html`)
3. **Каталог** (`catalog.php`) ← единственная PHP-страница, тянет товары из БД
4. **Почему мы** (`why.html`)
5. **FAQ** (`faq.html`)

## Тема дизайна
Белый фон + спектр голубого (от светло-голубого до глубокого синего). Минималистично, чисто, медицинская опрятность.
