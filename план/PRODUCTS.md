# Примеры товаров и категорий

## Категории
1. **Стельки** (`insoles`)
2. **Обувь** (`shoes`)
3. **Корсеты и бандажи** (`corsets`)
4. **Аксессуары** (`accessories`) — опционально

## Шаблон карточки в каталоге
```
┌─────────────────────────────┐
│       [картинка товара]     │
├─────────────────────────────┤
│ Название модели             │
│ от 1490 ₽                   │
│                             │
│ Размеры: [36] [37] [38] [40]│  ← бейджи, недоступные затемнены
│                             │
│ Короткое описание в две     │
│ строки максимум.            │
│                             │
│ ⛨ Поддержка свода стопы    │  ← 2-3 крутых свойства
│ ◇ Антибакт. покрытие        │
│ ◐ Легкий материал           │
│                             │
│        [ Подробнее ]        │
└─────────────────────────────┘
```
