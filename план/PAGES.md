# Описание страниц

## 1. Главная — `index.html` (статика)
**Цель:** дать первое впечатление и направить в каталог.

**Блоки:**
- Hero: большой заголовок «Ortobase — забота о ваших ногах» + подпись + кнопка «В каталог»
- 3 преимущества коротко (иконки + 1 строчка текста)
- Блок «Популярные товары» — 3-4 захардкоженных карточки (просто как тизер; динамика на полной странице каталога)
- Краткая врезка «Почему мы» со ссылкой на `why.html`

> На главной товары захардкожены — это нормально для лендинга. Реальные данные на `catalog.php`.

---

## 2. О нас — `about.html` (статика)
**Цель:** рассказать про магазин.

**Блоки:**
- Заголовок «О Ortobase»
- 2 колонки: слева текст (история, миссия), справа фото магазина/команды
- Цифры в плитках: «5 лет на рынке», «3000+ клиентов», «50+ моделей в наличии»
- Контакты внизу (адрес, телефон, часы)

---

## 3. Каталог — `catalog.php` (PHP + БД) ⭐
**Цель:** показать товары из базы.

**Что делает PHP:**
1. Подключается к БД через `includes/db.php`
2. Если есть `$_GET['category']` — фильтрует
3. Тянет товары + их размеры + 2-3 свойства
4. Рендерит сетку карточек

**Блоки:**
- Хедер «Каталог»
- Слева: список категорий (ссылки `?category=...`)
- Справа: сетка карточек товаров (Bootstrap `row-cols-1 row-cols-md-3 g-4`)

**Карточка товара содержит:**
- Картинка
- Название
- Цена (от … ₽)
- Доступные размеры (бейджики `<span class="badge">`, серые если нет в наличии)
- Краткое описание (1–2 строки)
- 2–3 «крутых свойства» как иконки или цветные бейджи (визуальный хук)
- Кнопка «Подробнее» → открывает модалку Bootstrap с расширенным описанием

---

## 4. Почему мы — `why.html` (статика)
**Цель:** перечислить преимущества.

**Блоки:**
- Заголовок «Почему выбирают Ortobase»
- 6 плиток с иконками Bootstrap Icons:
  1. Сертифицированные товары
  2. Большой выбор размеров
  3. Консультация ортопеда
  4. Возврат 14 дней
  5. Доставка по городу
  6. Скидки постоянным клиентам

---

## 5. FAQ — `faq.html` (статика)
**Цель:** снять типовые возражения.

**Блоки:**
- Заголовок «Часто задаваемые вопросы»
- Bootstrap-аккордеон, вопросы прописаны прямо в HTML

**Примеры вопросов:**
- «Как подобрать размер стелек?»
- «Можно ли вернуть товар?»
- «Делаете ли вы стельки на заказ?»
- «Как ухаживать за ортопедической обувью?»
- «Можно ли носить ортопедическую обувь каждый день?»

> Изначально планировал хранить FAQ в БД, но раз страница статичная — проще прописать аккордеон в HTML руками. БД остается только для каталога.
