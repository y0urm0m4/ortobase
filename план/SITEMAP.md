# Карта сайта

```
Ortobase
│
├── /                        index.html      (HTML)
│
├── /О нас                   about.html      (HTML)
│
├── /Каталог                 catalog.php     (PHP — тянет товары из БД)
│   ├── ?category=insoles
│   ├── ?category=shoes
│   └── ?category=corsets
│
├── /Почему мы               why.html        (HTML)
│
└── /FAQ                     faq.html        (HTML)
```

## Навигация (навбар)
Один и тот же навбар во всех 5 файлах (копи-паст):

| Пункт меню | Файл           |
| ---------- | -------------- |
| Главная    | `index.html`   |
| О нас      | `about.html`   |
| Каталог    | `catalog.php`  |
| Почему мы  | `why.html`     |
| FAQ        | `faq.html`     |

## Логика переходов
- С главной → ссылка «Смотреть каталог» ведет на `catalog.php`
- В каталоге клик по категории в сайдбаре → `catalog.php?category=...`
- Карточка товара — раскрывается модалкой Bootstrap прямо в каталоге (не делаем отдельную страницу, чтобы не плодить PHP)
- В FAQ — все вопросы на одной странице, аккордеон Bootstrap
