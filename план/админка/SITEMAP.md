# Карта сайта

## Публичная часть

```
public/
│
├── /                        index.html      Главная (лендинг)
├── /О нас                   about.html      История, команда, контакты
├── /Каталог                 catalog.html    Сетка товаров + модалки
├── /Почему мы               why.html        6 преимуществ
└── /FAQ                     faq.html        Аккордеон вопросов
```

Все 5 страниц — **чистая статика**. Данные товаров захардкожены прямо в HTML.

### Навбар публички (5 пунктов)

| Пункт меню | Файл           |
| ---------- | -------------- |
| Главная    | `index.html`   |
| О нас      | `about.html`   |
| Каталог    | `catalog.html` |
| Почему мы  | `why.html`     |
| FAQ        | `faq.html`     |

Один и тот же навбар во всех 5 файлах (копи-паст). Подсветка активного пункта — через `assets/js/script.js` по `location.pathname`.

---

## Админ-панель

```
public/admin/
│
├── /Login                   login.html         Форма входа (фейковая)
├── /Дэшборд                 dashboard.html     KPI + графики + лента
├── /Каталог                 catalog.html       Таблица товаров с CRUD-модалкой
├── /Пользователи            users.html         Таблица сотрудников
├── /Категории               categories.html    (опционально)
└── /Настройки               settings.html      (опционально)
```

### Сайдбар админки (выносится в `partials/sidebar.html`)

| Секция   | Пункт          | Файл               |
| -------- | -------------- | ------------------ |
| Главное  | Дэшборд        | `dashboard.html`   |
| Главное  | Каталог        | `catalog.html`     |
| Главное  | Категории      | `categories.html`  |
| Доступ   | Пользователи   | `users.html`       |
| Доступ   | Настройки      | `settings.html`    |

Сайдбар грузится через jQuery `$.load('partials/sidebar.html')` на каждой странице админки. Активный пункт определяется атрибутом `data-page="dashboard"` на `<body>`.

### Топбар админки (выносится в `partials/topbar.html`)

Общий для всех страниц админки кроме `login.html`. Содержит:
- Бургер (только на мобилке) — открывает offcanvas-сайдбар
- Хлебные крошки
- Поиск
- Иконка уведомлений
- Кнопка переключения тем (луна/солнце)
- Аватар + имя пользователя

## Логика переходов

### Публичка
- С главной → ссылка «Смотреть каталог» ведёт на `catalog.html`
- В каталоге клик по категории в сайдбаре — пока без фильтрации (статика)
- Карточка товара — раскрывается модалкой Bootstrap

### Админка
- Незалогиненный заходит на `dashboard.html` напрямую — **никаких проверок нет**, это болванка
- Кнопка «Войти» в `login.html` — это `<a href="dashboard.html">`, не форма
- Между админ-страницами — обычные ссылки
- Выход — пункт в сайдбаре редиректит на `login.html` (или на публичный `index.html`)

## Где живёт что — пути

- Публичка: `http://127.0.0.1:5500/public/index.html`
- Админка: `http://127.0.0.1:5500/public/admin/login.html`
- Partials грузятся относительно текущей страницы: `partials/sidebar.html`
