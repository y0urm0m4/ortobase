# Структура файлов админки

## Раскладка

```
public/admin/
│
├── login.html                  Отдельный layout, без сайдбара/топбара
├── dashboard.html              Главная страница админки
├── catalog.html                Управление каталогом
├── users.html                  Пользователи
├── categories.html             (опционально)
├── settings.html               (опционально)
│
├── partials/                   Общие фрагменты для всех страниц кроме login
│   ├── sidebar.html            Левая навигация
│   └── topbar.html             Верхняя панель
│
└── assets/
    ├── css/
    │   ├── base.css            Структура + кастомные классы (не зависит от темы)
    │   ├── light.css           :root с переменными светлой темы
    │   └── dark.css            :root с переменными тёмной темы (те же имена)
    └── js/
        ├── theme.js            Переключатель темы + localStorage
        ├── layout.js           jQuery $.load() для sidebar/topbar + подсветка active
        └── admin.js            Фильтры таблиц, поиск, прочая логика (создаётся по мере необходимости)
```

## Что в каком файле

### `base.css`

Кастомные стили, не зависящие от темы. Использует `var(--имя)` для цветов — значения подставляются из текущей темы.

Содержит:
- Базовый шрифт для `body`
- `.app-sidebar` — стилизация сайдбара (ширина, padding, цвет фона через переменную)
- `.app-sidebar .nav-link` — пункты меню (hover, active)
- `.app-sidebar .section-label` — метки секций («Главное», «Доступ»)
- `.app-topbar` — стилизация топбара
- `.app-main` — отступы под фиксированные сайдбар/топбар + медиа-запрос для ≥992px
- `.app-content` — внутренние отступы контента
- (По мере необходимости) — стили KPI-карточек, прогресс-баров, аватаров-инициалов

### `light.css`

Только `:root { --имя: значение; ... }` для светлой темы.

Группы переменных:
- Фоны (`--bg-page`, `--bg-card`, `--bg-sidebar`, `--bg-soft`, `--bg-input`)
- Текст (`--text-main`, `--text-muted`, `--text-sidebar`, `--text-sidebar-muted`)
- Границы (`--border`, `--border-input`)
- Акценты (`--accent`, `--accent-hover`, `--accent-active`)
- Семантика (`--success`, `--warning`, `--danger`, `--info`)
- Переопределения Bootstrap (`--bs-body-bg`, `--bs-body-color`, etc.)

### `dark.css`

То же самое что `light.css`, но с другими значениями. Имена переменных — **точно те же**.

### `theme.js`

IIFE-функция, выполняется при загрузке страницы.

Что делает:
1. Читает `localStorage.getItem('ortobase-theme')`
2. Применяет текущую тему через `applyTheme()`:
   - `<html>.setAttribute('data-bs-theme', theme)`
   - `<link id="theme-css">.setAttribute('href', 'assets/css/{theme}.css')`
   - Меняет иконку кнопки (`bi-moon` ↔ `bi-sun`)
3. Навешивает обработчик клика на `#themeToggle` — инвертирует тему, сохраняет в localStorage

### `layout.js`

jQuery-загрузчик partials. Выполняется при `$(document).ready`.

Что делает:
1. Параллельно грузит `partials/sidebar.html` в `#sidebar-mount` и `partials/topbar.html` в `#topbar-mount`
2. После завершения обеих загрузок — читает `data-page` с `<body>`, находит `.nav-link[data-page="..."]` в сайдбаре и добавляет ему класс `.active`

### `admin.js` (по мере необходимости)

Будет содержать:
- jQuery-фильтры таблиц (по табам и поиску)
- Обработчики модалок
- Прочая страничная логика

Создаётся постранично — на дашборде ничего особо не нужно, на каталоге появится фильтрация, на users — то же самое.

## Антифлеш-скрипт

Должен стоять **первым** в `<head>` всех админских страниц:

```html
<script>
  (function() {
    const t = localStorage.getItem('ortobase-theme') || 'light';
    document.documentElement.setAttribute('data-bs-theme', t);
  })();
</script>
```

Без него — мерцание при переключении между страницами с тёмной темой.

## Шаблон админ-страницы

Каждая страница кроме `login.html` строится по одной схеме:

```html
<!DOCTYPE html>
<html lang="ru">
<head>
  <!-- 1. Антифлеш -->
  <script>(function() {
    const t = localStorage.getItem('ortobase-theme') || 'light';
    document.documentElement.setAttribute('data-bs-theme', t);
  })();</script>

  <!-- 2. Мета и заголовок -->
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>... · Ortobase</title>

  <!-- 3. CDN-ресурсы -->
  <link href=".../bootstrap.min.css" rel="stylesheet">
  <link href=".../bootstrap-icons.min.css" rel="stylesheet">

  <!-- 4. Свои стили -->
  <link rel="stylesheet" href="assets/css/base.css">
  <link id="theme-css" rel="stylesheet" href="assets/css/light.css">
</head>
<body data-page="ИМЯ_СТРАНИЦЫ">

  <!-- 5. Mount-точки для partials -->
  <div id="sidebar-mount"></div>
  <div id="topbar-mount"></div>

  <!-- 6. Уникальный контент страницы -->
  <main class="app-main">
    <div class="app-content">
      <!-- ... -->
    </div>
  </main>

  <!-- 7. JS — порядок важен: jQuery → BT5 → свои скрипты -->
  <script src=".../jquery.min.js"></script>
  <script src=".../bootstrap.bundle.min.js"></script>
  <script src="assets/js/layout.js"></script>
  <script src="assets/js/theme.js"></script>
  <!-- по необходимости: <script src="assets/js/admin.js"></script> -->
</body>
</html>
```

## Login — особый случай

`login.html` НЕ использует partials и НЕ инжектит sidebar/topbar.

Подключает:
- BT5 + Icons
- `base.css` + `light.css` (или `dark.css`)
- `theme.js` (для кнопки переключения)

НЕ подключает:
- `layout.js` (нечего загружать)
- `admin.js` (логика страницы здесь минимальная)
- jQuery (не нужен на этой странице вообще)

Кнопка-луна в `login.html` ставится прямо в HTML страницы (отдельно, не из топбара).
