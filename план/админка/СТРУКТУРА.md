# Структура файлов и БД для админки

## Файлы

Кладём всю админку в подпапку `public/admin/` — она отделена от публичного сайта, но живёт в том же DocumentRoot.

```
public/
├── (existing public files: index.html, about.html, …)
│
└── admin/
    ├── index.php              ← главная админки = редирект на dashboard.php
    ├── login.php              ← страница входа (свой layout)
    ├── logout.php             ← выход (destroy session + redirect)
    ├── dashboard.php          ← дэшборд
    ├── catalog.php            ← управление каталогом
    ├── categories.php         ← управление категориями   (опционально)
    ├── users.php              ← управление пользователями
    ├── settings.php           ← настройки магазина        (опционально)
    │
    ├── layout/
    │   ├── head.php           ← <head>, подключения CSS, тема
    │   ├── sidebar.php        ← левый сайдбар (общий)
    │   ├── topbar.php         ← верхняя панель с поиском и аватаром
    │   └── foot.php           ← подключение JS + </body></html>
    │
    ├── includes/
    │   ├── auth.php           ← session_start + проверка авторизации
    │   ├── helpers.php        ← e(), formatPrice(), timeAgo(), initials(), avatarColor()
    │   └── activity.php       ← logActivity($pdo, $type, $payload)
    │
    ├── api/                   ← обработчики POST-запросов (форм)
    │   ├── product_save.php   ← create + update товара
    │   ├── product_delete.php
    │   ├── user_invite.php
    │   ├── user_toggle.php
    │   └── category_save.php  (опционально)
    │
    └── assets/
        ├── css/admin.css      ← стили админки (палитра обеих тем)
        ├── js/theme.js        ← переключатель темы
        ├── js/table-filter.js ← поиск и фильтры таблиц
        └── js/admin.js        ← общие сборки
```

> `includes/db.php` уже есть в `public/includes/`. Из админки путь до него: `../includes/db.php`.

## Изменения в БД

К существующим 4 таблицам добавляем 2 новые: `admin_users` и `activity_log`.

### `admin_users` — учётки сотрудников
| поле           | тип          | примечание                                   |
| -------------- | ------------ | -------------------------------------------- |
| id             | INT PK AI    |                                              |
| name           | VARCHAR(100) | «Анна Соколова»                              |
| email          | VARCHAR(150) | UNIQUE, логин для входа                      |
| password_hash  | VARCHAR(255) | через `password_hash()`                      |
| role           | VARCHAR(30)  | `admin` / `manager` / `content`              |
| status         | VARCHAR(20)  | `active` / `invited` / `disabled`            |
| avatar_color   | VARCHAR(20)  | HEX или ключ цвета для фона аватара          |
| last_seen_at   | DATETIME     | NULL для не входивших                        |
| created_at     | DATETIME     | DEFAULT CURRENT_TIMESTAMP                    |

### `activity_log` — события для ленты
| поле        | тип          | примечание                                            |
| ----------- | ------------ | ----------------------------------------------------- |
| id          | INT PK AI    |                                                       |
| user_id     | INT FK       | → `admin_users.id` (кто сделал)                       |
| type        | VARCHAR(40)  | `product_create`, `product_update`, `user_invite`, …  |
| payload     | TEXT         | JSON-строка с деталями (что именно изменилось)        |
| created_at  | DATETIME     | DEFAULT CURRENT_TIMESTAMP                             |

### SQL миграции (отдельным файлом `sql/admin.sql`)

```sql
USE ortobase;

CREATE TABLE admin_users (
  id            INT AUTO_INCREMENT PRIMARY KEY,
  name          VARCHAR(100) NOT NULL,
  email         VARCHAR(150) NOT NULL UNIQUE,
  password_hash VARCHAR(255) NOT NULL,
  role          VARCHAR(30)  NOT NULL DEFAULT 'manager',
  status        VARCHAR(20)  NOT NULL DEFAULT 'active',
  avatar_color  VARCHAR(20)  DEFAULT NULL,
  last_seen_at  DATETIME     DEFAULT NULL,
  created_at    DATETIME     DEFAULT CURRENT_TIMESTAMP
);

CREATE TABLE activity_log (
  id         INT AUTO_INCREMENT PRIMARY KEY,
  user_id    INT NOT NULL,
  type       VARCHAR(40)  NOT NULL,
  payload    TEXT,
  created_at DATETIME     DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (user_id) REFERENCES admin_users(id) ON DELETE CASCADE
);
```

## Доступ к админке

- Публичная часть: `http://localhost/ortobase/` → `index.html` и т.д.
- Админка: `http://localhost/ortobase/admin/` → редирект на `login.php` если не залогинен, иначе `dashboard.php`.

## Что **не** делаем в админке (упрощения для курсовой)

- ✗ Регистрация открытая — только приглашения через админа.
- ✗ Восстановление пароля по почте — пишем «обратитесь к администратору» (для курсача хватит).
- ✗ Двухфакторка, OAuth и прочее.
- ✗ Реальная загрузка картинок на диск — храним URL в поле `image`. (Можно потом добавить как бонус.)
- ✗ Серверная пагинация в таблицах — товаров мало, всё на клиенте.
