# Уроки: верстаем админку по шагам

Учебный режим: на каждом шаге сперва короткая теория, потом верстка/код. Идём от простого к сложному.

---

## 🎓 Урок 1. Каркас и общий layout
**Что строим:** пустая страница `admin/index.php` с сайдбаром и топбаром (без контента).

**Что учим:**
- Как разложить страницу на 2 области (сайдбар + main) через **Bootstrap-сетку** или **flex**.
- Что такое `position: fixed` для сайдбара и почему он не «съезжает» при скролле.
- Как переиспользовать общие куски HTML через PHP `include`/`require`, чтобы не копипастить навбар во все файлы.
- Иерархия CSS-переменных (мы их уже завели — расширим под админ-палитру).

**Файлы:** `admin/layout/sidebar.php`, `admin/layout/topbar.php`, `admin/layout/head.php`, `admin/layout/foot.php`, `admin/index.php`.

---

## 🎓 Урок 2. Светлая и тёмная тема
**Что строим:** иконка-переключатель темы в топбаре. При клике вся админка перекрашивается.

**Что учим:**
- **CSS-переменные** в `:root` против `[data-theme="dark"]` — как одно переопределяет другое.
- Что такое `localStorage` в JS и как им сохранить выбор пользователя между загрузками.
- Как избежать «вспышки» неправильной темы при загрузке страницы (применяем тему ДО рендера).
- Атрибуты `data-*` на HTML-элементах — для чего они нужны.

**Файлы:** `admin/assets/css/admin.css` (палитра обеих тем), `admin/assets/js/theme.js`.

---

## 🎓 Урок 3. Страница входа (Login)
**Что строим:** `admin/login.php` — отдельный layout (без сайдбара), форма e-mail+пароль.

**Что учим:**
- **PHP-сессии** (`session_start()`, `$_SESSION`) — что это, где хранится, как живёт.
- Почему пароли в БД хранятся **хешем**, а не текстом. `password_hash()` и `password_verify()`.
- Как обработать POST-форму на том же файле (`<form method="post">`).
- **CSRF-токен** — что это и как простую защиту прикрутить (можно опционально).
- Редиректы в PHP через `header('Location: …')` и почему важно делать это до любого вывода.
- Как защитить остальные страницы (`auth_check.php`, который мы инклюдим в начало каждого `admin/*.php`).

**Файлы:** `admin/login.php`, `admin/logout.php`, `admin/includes/auth.php`. Новая таблица `admin_users`.

---

## 🎓 Урок 4. Дэшборд: KPI-карточки
**Что строим:** 4 карточки сверху дэшборда — «Товары / Категории / Нет в наличии / Пользователи» с цифрами из БД.

**Что учим:**
- Что такое **агрегатные SQL-запросы** (`COUNT()`, `SUM()`, `GROUP BY`).
- Сетка Bootstrap для 4 равных колонок (`row-cols-md-4`, `g-3`).
- Как сверстать цветной маркер-квадратик справа в карточке (BT5 утилиты + `:after` или просто `<span>`).
- Динамическая подпись «+2 за неделю» / «без изменений» / «+3 размера».

**Файлы:** `admin/dashboard.php` (часть 1).

---

## 🎓 Урок 5. Дэшборд: бар-чарт без библиотек
**Что строим:** график «Просмотры каталога · 14 дней» — столбики разной высоты, последний — синий.

**Что учим:**
- **Flexbox** с `align-items: end` — как заставить столбики стоять на «полу».
- Высота столбика через inline-стиль (`style="height: 70%"`) — пропорционально максимуму.
- Табы «7д / 14д / 30д» как переключатель — Bootstrap Tabs или своя группа кнопок.
- Опционально: где брать данные. Захардкодим массив в PHP, чтоб не усложнять.

**Файлы:** `admin/dashboard.php` (часть 2).

---

## 🎓 Урок 6. Дэшборд: лента активности + Топ категорий
**Что строим:** правый блок «Топ категорий» (3 строки с прогресс-барами) + нижний блок «Лента активности».

**Что учим:**
- **Кастомный прогресс-бар** на двух `<div>` (трек + заполнение).
- Аватары-инициалы — как сгенерить из имени («Анна Соколова» → «АС»), цветной фон.
- Новая таблица `activity_log` и как туда писать события.
- Форматирование «5 мин назад» / «1 ч назад» из timestamp — функция на PHP.

**Файлы:** `admin/dashboard.php` (часть 3). Новая таблица `activity_log`.

---

## 🎓 Урок 7. Каталог: таблица товаров (read-only)
**Что строим:** `admin/catalog.php` — таблица товаров с колонками: товар (с миниатюрой), категория, цена, размеры, наличие, popularity, действия.

**Что учим:**
- Как из БД достать товар + все размеры + категорию **одним JOIN-запросом** и сгруппировать на PHP.
- Размеры-бейджи на серых неактивных размерах — мы уже умеем, повторим.
- Popularity-бар (тот же кастомный прогресс из урока 6).
- Bootstrap **Tabs** для «Все · 9 / Стельки · 3 / Обувь · 3 / Корсеты · 3» (фильтр без перезагрузки на чистом JS).

**Файлы:** `admin/catalog.php`.

---

## 🎓 Урок 8. Каталог: поиск по таблице на чистом JS
**Что строим:** инпут «Поиск товаров…» — фильтрует строки таблицы по мере ввода.

**Что учим:**
- Событие `input` на текстовом поле.
- `document.querySelectorAll` и итерация по DOM.
- Манипуляция `display: none` через `element.style` или `classList`.
- Регистронезависимый поиск (`toLowerCase()`).

**Файлы:** дополнения в `admin/catalog.php` + новый `admin/assets/js/table-filter.js`.

---

## 🎓 Урок 9. CRUD товаров: модалка «Добавить / Редактировать»
**Что строим:** кнопка «Добавить товар» открывает модалку с формой. Та же модалка переиспользуется для редактирования при клике «...» → «Изменить».

**Что учим:**
- Bootstrap **Modal**, как открыть и закрыть программно.
- Как одну модалку использовать и для create, и для edit (передавая `id`).
- POST-обработчик в отдельном файле `admin/api/product_save.php` (вход — `$_POST`, выход — редирект).
- `<select>` для категорий, `<input type="file">` для картинки (или просто URL-инпут — упростим).
- Динамические поля для размеров — добавление/удаление input'ов через JS.

**Файлы:** `admin/catalog.php` (модалка), `admin/api/product_save.php`, `admin/api/product_delete.php`.

---

## 🎓 Урок 10. Пользователи: таблица + статусы
**Что строим:** `admin/users.php` — список сотрудников с аватаром-инициалами, ролью, статусом (Активен / Приглашён / Отключён), last seen.

**Что учим:**
- Те же фильтр-табы и поиск, что в каталоге (повторяем закреплённые знания).
- Бейджи статусов с разными цветами через class-модификаторы.
- Аватары с разноцветным фоном — детерминированный цвет по хешу имени.
- Конвертация `last_seen_at` → «5 мин назад / вчера / 3 дня назад».

**Файлы:** `admin/users.php`.

---

## 🎓 Урок 11. CRUD пользователей: пригласить / отключить
**Что строим:** кнопка «Пригласить» → модалка с e-mail + ролью. «...» у юзера → возможность отключить.

**Что учим:**
- Генерация случайного пароля для приглашённых.
- Статусы как машина состояний (новый → приглашён → активен → отключён).
- Защита: нельзя удалить/отключить самого себя.
- Опционально: email-уведомление о приглашении (только моковая отправка, без реальной почты).

**Файлы:** `admin/api/user_invite.php`, `admin/api/user_toggle.php`.

---

## 🎓 Урок 12 (опционально). Категории и Настройки
Доделываем два оставшихся пункта меню из дизайна:
- `admin/categories.php` — простой CRUD категорий.
- `admin/settings.php` — поля для настроек магазина (название, контакты). Можно хранить в таблице `settings` key-value.

## Резюме: что освоим к концу

- **Bootstrap 5**: сетка, flex-утилиты, Modal, Tabs, Forms, утилиты bg/text/border.
- **JavaScript (vanilla)**: события, манипуляция DOM, localStorage, fetch (если решим делать AJAX), темы.
- **PHP**: сессии, авторизация, хеш паролей, PDO + JOIN, обработка форм, редиректы, простой роутинг.
- **MySQL**: JOIN'ы, COUNT/GROUP BY, INSERT/UPDATE/DELETE, foreign keys.
- **CSS**: переменные, темы, кастомные прогресс-бары, аватары.
