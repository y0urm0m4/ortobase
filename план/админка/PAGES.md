# Описание страниц публички

> Все 5 страниц — чистая статика (HTML + CSS + Bootstrap + минимум JS). Данные товаров захардкожены.

## 1. Главная — `index.html`

**Цель:** дать первое впечатление и направить в каталог.

**Блоки:**
- **Hero** — большой заголовок «Забота о ваших ногах начинается здесь», бейдж сертификации, две кнопки («Смотреть каталог», «Почему мы»), фоновое изображение
- **3 преимущества** — иконки + одна строка текста (Сертификаты / Подбор по размеру / Консультация ортопеда)
- **Популярные товары** — 4 тизер-карточки (Comfort+, OrthoSoft Casual, BackFix Pro, ActiveRun)
- **Врезка «Почему выбирают Ortobase»** — заголовок + CTA-кнопка на `why.html`

## 2. О нас — `about.html`

**Цель:** рассказать про магазин.

**Блоки:**
- **Шапка** с хлебными крошками
- **История** — 2 колонки: слева текст (миссия, ценности), справа фото магазина
- **Цифры в плитках** — 5 лет, 3000+ клиентов, 50+ моделей, 100% сертификаты
- **Команда** — 3 карточки с фото и должностью (Анна, Дмитрий, Мария)
- **Контакты** — адрес, телефон, e-mail

## 3. Каталог — `catalog.html` ⭐

**Цель:** показать ассортимент.

**Блоки:**
- **Шапка** с хлебными крошками и заголовком
- **Сайдбар категорий** (слева) — Все товары / Стельки / Обувь / Корсеты (ссылки заглушки — у нас единая страница, без реальной фильтрации)
- **Информационная плашка** под сайдбаром — «Нужна консультация?» с кнопкой звонка
- **Сетка из 6 товаров** (справа) в Bootstrap-сетке `row-cols-1 row-cols-sm-2 row-cols-xl-3`

**Карточка товара содержит:**
- Картинка (placeholder.co)
- Категория + название
- Цена
- Бейджи размеров (некоторые с `out-of-stock` — затемнены и зачёркнуты)
- Краткое описание
- 2 «фичи-чипа» с иконками
- Кнопка «Подробнее» → открывает модалку

**Модалка** (6 штук, по одной на товар) — расширенное описание, все размеры, полный список ключевых свойств, кнопка «Узнать наличие».

## 4. Почему мы — `why.html`

**Цель:** перечислить преимущества подробно.

**Блоки:**
- **Шапка** с крошками
- **Лид-текст** по центру
- **6 плиток с иконками:**
  1. Сертифицированные товары
  2. Большой выбор размеров
  3. Консультация ортопеда
  4. Возврат 14 дней
  5. Доставка по городу
  6. Скидки постоянным клиентам
- **CTA-блок** «Убедились? Смотрите каталог»

## 5. FAQ — `faq.html`

**Цель:** снять типовые возражения.

**Блоки:**
- **Шапка** с крошками
- **Bootstrap-аккордеон** с 7 вопросами (подбор размера, возврат, заказ стелек, уход, ежедневная носка, доставка, сертификаты)
- **CTA** «Остались вопросы?» с кнопкой звонка

---

## Что одинаково на всех страницах

- **Навбар сверху** (тёмно-синий) — копи-пастится в каждый из 5 файлов
- **Футер снизу** (тёмно-синий) — тоже копи-паст
- **Шрифт Inter** через Google Fonts (импорт в `style.css`)
- **CSS-переменные** в `:root` для всей палитры
- **Подсветка активного пункта** меню — `script.js` пробегает по `nav-link` и сравнивает `href` с текущим путём
