# Админ-панель Ortobase

Поверх готового публичного сайта строим закрытую часть — админку для управления каталогом и пользователями. Дизайн уже готов: 8 PNG-макетов в папке [`дизайн/`](../../дизайн/).

## Что нужно сверстать (из макетов)

| Экран            | Файл макета                                          | Что показывает                                                                  |
| ---------------- | ---------------------------------------------------- | ------------------------------------------------------------------------------- |
| **Login**        | `Login — Light.png` + `Login — Dark.png`             | Форма входа (e-mail, пароль, «запомнить меня», ссылка «забыли пароль»)          |
| **Дэшборд**      | `Dashboard — Light.png` + `Dashboard — Light-1.png`* | 4 KPI-карточки + бар-чарт «Просмотры каталога» + «Топ категорий» + лента событий |
| **Каталог**      | `Catalog — Light.png` + `Catalog — Light-1.png`*     | Таблица товаров с фильтрами-табами, поиском, размерами, наличием, popularity-баром, кнопкой «...» |
| **Пользователи** | `Users — Light.png` + `Users — Light-1.png`*         | Таблица сотрудников: аватар-инициалы, e-mail, роль, статус, last seen          |

> *Файлы с суффиксом `-1` — это тёмная тема того же экрана.

## Общая идея layout

Все экраны кроме Login имеют одинаковый каркас:

```
┌────────────┬──────────────────────────────────────────┐
│            │  ХЛЕБНЫЕ КРОШКИ      [поиск]   [🔔][⊞][AC]│   ← топбар
│  Ortobase  ├──────────────────────────────────────────┤
│            │                                          │
│  Главное   │  ЗАГОЛОВОК               [кнопки справа] │
│  • Дэшборд │  подзаголовок                            │
│  • Каталог │                                          │
│  • Категор.│  ┌──────────────────────────────────┐   │
│            │  │                                  │   │
│  Доступ    │  │      КОНТЕНТ РАЗДЕЛА             │   │
│  • Юзеры   │  │                                  │   │
│  • Настр.  │  └──────────────────────────────────┘   │
│            │                                          │
│  v0.1      │                                          │
└────────────┴──────────────────────────────────────────┘
   САЙДБАР               ОСНОВНАЯ ОБЛАСТЬ
```

- **Сайдбар** тёмно-синий (`#0B2545`), всегда виден на ≥768px, на мобилке — выезжает.
- **Топбар** белый, с хлебными крошками слева, поиском по центру, иконками и аватаром справа.
- **Контент** — серый фон (`#F4F7FB`), внутри белые блочки-карточки.

## Что нового по сравнению с публичной частью

Новые штуки, которых не было в витрине:
1. **Авторизация** — сессии PHP, хеш паролей, защита админ-страниц.
2. **CRUD** — создание/редактирование/удаление товаров, категорий, пользователей.
3. **Темы** (Light/Dark) — переключатель темы через CSS-переменные и `localStorage`.
4. **Таблицы с фильтрами и поиском** — без серверной пагинации (товаров мало).
5. **График** — простой бар-чарт. Сделаем своими руками на CSS-флексе, без Chart.js.
6. **Лента активности** — отдельная таблица в БД, пишем туда события при действиях.
