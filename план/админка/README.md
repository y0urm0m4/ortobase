# Ortobase — общая сводка

Курсовой/коляжный проект: сайт-витрина ортопедического магазина **Ortobase** + админ-панель.

## Цель

Демонстрационный фронтенд-проект: публичная витрина магазина и админ-панель управления каталогом. Без бэкенда — это **визуальная болванка**, демонстрирующая UX/UI и владение фронтовым стеком.

> Это коляжный проект — упор на наглядность вёрстки и интерактив на стороне браузера. Без БД, авторизации, оплаты, серверной логики. Данные захардкожены в HTML.

## Стек

- **HTML5** — структура страниц
- **CSS3** — кастомные стили, CSS-переменные, темы (light/dark)
- **Bootstrap 5.3** — основа разметки, утилиты, готовые компоненты (`offcanvas`, `modal`, `navbar`, `accordion`, `card`, `form-control`)
- **Bootstrap Icons** — иконографика
- **JavaScript (vanilla)** — переключение тем, перехват событий, мелкие интеракции
- **jQuery 3.7** — склейка общих фрагментов (`$.load()`), фильтрация таблиц, удобство манипуляции DOM

Никакого PHP, MySQL, Node.js. Открывается через Live Server (или Five Server) — обычная статика.

## Структура проекта (верхнеуровневая)

```
ortobase/
├── public/
│   ├── (5 страниц публички)
│   ├── admin/         (страницы админки + partials + js)
│   └── assets/        (CSS/JS/изображения публички)
├── дизайн/            (PNG-макеты Figma)
└── план/              (документация — то, что вы читаете)
```

Подробнее см. [STRUCTURE.md](STRUCTURE.md).

## Публичная часть — 5 страниц

1. **Главная** (`index.html`) — лендинг с hero и тизерами товаров
2. **О нас** (`about.html`) — история, команда, контакты
3. **Каталог** (`catalog.html`) — сетка товаров, фильтр по категориям, модалки
4. **Почему мы** (`why.html`) — 6 преимуществ
5. **FAQ** (`faq.html`) — Bootstrap-аккордеон

Все товары/данные захардкожены прямо в HTML. На главной — 4 тизер-карточки, в каталоге — 6 полноценных товаров.

## Админ-панель — 4–6 страниц

1. **Login** (`admin/login.html`) — форма входа (фейковая — кнопка просто редиректит на дашборд)
2. **Дэшборд** (`admin/dashboard.html`) — KPI-карточки, график, лента активности, топ категорий
3. **Каталог** (`admin/catalog.html`) — таблица товаров с фильтрами, поиском, модалкой добавления
4. **Пользователи** (`admin/users.html`) — таблица сотрудников
5. **Категории** (`admin/categories.html`) — опционально
6. **Настройки** (`admin/settings.html`) — опционально

Сайдбар и топбар общие — выносятся в `admin/partials/`, подгружаются через jQuery `$.load()`.

## Тема дизайна

- **Светлая тема:** белый + спектр голубого (от `#F0F8FF` до `#0B2545`)
- **Тёмная тема:** глубокий тёмно-синий фон + те же акценты
- Переключение — кнопкой в топбаре, выбор сохраняется в `localStorage`
- Технически: подмена `href` у `<link>` тега темы + атрибут `data-bs-theme` на `<html>` для адаптации BT5-компонентов

Подробности в [DESIGN.md](DESIGN.md).
