# Дизайн-система

## Принципы

- **База** — Bootstrap 5.3 (готовые компоненты + утилиты)
- **Кастом** — только там, где BT5 не справляется (сайдбар, прогресс-бары, аватары)
- **Цвета** — через CSS-переменные, никаких хардкод-хексов вне файлов тем
- **Темы** — две (light + dark), переключение подменой CSS-файла

## Цветовая палитра

Тема: **белый + спектр голубого** для светлой, **тёмно-синий с теми же акцентами** для тёмной.

## Темы — техническая реализация

### Файлы тем

```
admin/assets/css/
├── base.css       Кастомные стили + структура (НЕ зависит от темы)
├── light.css      Только :root { --... } для светлой темы
└── dark.css       Только :root { --... } для тёмной темы (те же имена)
```

**Принцип:** имена переменных одинаковые в обоих файлах темы. Меняются только значения. Базовая разметка в `base.css` использует `var(--имя)` и сама не знает, "светло сейчас или темно".

### Переменные тем (живут в light.css / dark.css)

```css
:root {
  /* Фоны */
  --bg-page             фон страницы
  --bg-card             фон карточек, инпутов
  --bg-sidebar          фон сайдбара (тёмно-синий в обеих темах)
  --bg-soft             светлый фон акцента (плашки, бейджи)
  --bg-input            фон инпутов

  /* Текст */
  --text-main           основной текст
  --text-muted          приглушённый
  --text-sidebar        текст на сайдбаре
  --text-sidebar-muted  приглушённый на сайдбаре

  /* Границы */
  --border              обычные границы
  --border-input        границы инпутов

  /* Акценты */
  --accent              голубой #3DA9FC (одинаковый в обеих темах)
  --accent-hover        синий #1E5F8E
  --accent-active       подсветка активного пункта в сайдбаре

  /* Семантика */
  --success             зелёный
  --warning             оранжевый
  --danger              красный
  --info                голубой

  /* Bootstrap-переменные — переопределяем чтобы BT5-компоненты адаптировались */
  --bs-body-bg          → var(--bg-page)
  --bs-body-color       → var(--text-main)
  --bs-secondary-color  → var(--text-muted)
  --bs-border-color     → var(--border)
  --bs-tertiary-bg      → var(--bg-soft)
}
```

### Переключение тем — механика

В `<head>` каждой админской страницы:
```html
<link rel="stylesheet" href="assets/css/base.css">
<link id="theme-css" rel="stylesheet" href="assets/css/light.css">
```

`id="theme-css"` нужен чтобы JS мог найти `<link>` и подменить `href`.

В `<html>` ставится атрибут `data-bs-theme="light"` или `data-bs-theme="dark"` — Bootstrap слушает этот атрибут для адаптации форм, чекбоксов, и т.д.

**JS-логика** (`assets/js/theme.js`):
1. При загрузке читает `localStorage.getItem('ortobase-theme')` — выбор пользователя
2. Применяет: `setAttribute('data-bs-theme', theme)` + подмена `href` у link
3. По клику на кнопку — инвертирует значение, сохраняет в `localStorage`
4. Меняет иконку (`bi-moon` ↔ `bi-sun`)

**Антифлеш-скрипт** — самым первым в `<head>` ставит атрибут `data-bs-theme` из localStorage, до загрузки CSS. Без него страница на долю секунды рендерится в светлой теме, потом перерисовывается в тёмной — мерцает.

## Типографика

- **Шрифт:** `Inter` (Google Fonts, 400/500/600/700), запасной `system-ui, sans-serif`
- **H1:** 2.5rem, 700, `var(--text-main)`
- **H2:** 2rem, 600
- **H3:** 1.25rem, 600
- **Body:** 1rem, 400, `var(--text-main)`
- **Small/muted:** 0.875rem, `var(--text-muted)`

## Компоненты (как реализованы)

### Кнопки
Используется BT5 `.btn.btn-primary`. Голубой цвет фона переопределяется через инлайн `style="background: var(--accent)"` либо через переопределение `--bs-primary` в темах.

### Карточки
BT5 `.card` + `.card-body`. Фон через `var(--bs-body-bg)` (адаптируется к теме). Тень — `shadow-sm` или `shadow`.

### Формы
BT5 `.form-control`, `.form-label`, `.form-check`. Тёмная тема работает «из коробки» благодаря `data-bs-theme="dark"` на `<html>`.

### Бейджи размеров (кастом)
Маленькие квадратики с числами/буквами. Зачёркнутые «out-of-stock» — серые с `text-decoration: line-through`.

### Фичи-чипы (кастом)
Пилюли с иконкой и текстом — для подсвечивания свойств товаров.

### Сайдбар админки (кастом)
Тёмно-синий блок 240px шириной, на мобилке прячется через BT5 `offcanvas-lg`. Активный пункт меню подсвечивается классом `.active` (добавляется JS-ом).

### Прогресс-бары (кастом)
Для popularity-баров и «Топ категорий» — два вложенных `<div>` (трек + заполнение). Заполнение через inline `style="width: 75%"`.

### Аватары-инициалы (кастом)
Круглый блок 32×32 с двумя буквами имени по центру и цветным фоном. Цвет генерируется JS-ом из хеша имени (или прописывается руками).

## Иконки

Bootstrap Icons через CDN. Примеры:
- `bi-heart-pulse-fill` — логотип медицинского магазина
- `bi-shield-check` — гарантия, сертификация
- `bi-rulers` — подбор по размеру
- `bi-truck` — доставка
- `bi-moon` / `bi-sun` — переключатель темы
- `bi-bell` — уведомления
- `bi-list` — бургер
- `bi-chevron-right` — разделитель хлебных крошек

## Адаптив

Bootstrap-брейкпойнты:
- xs (<576px) — мобила: одна колонка, бургер активен
- sm (576–767) — планшет узкий
- md (768–991) — планшет
- lg (992–1199) — десктоп: сайдбар выезжает из-за края, становится постоянным
- xl/xxl — широкий десктоп

Компоненты тёмной/светлой темы тестируются на всех брейкпойнтах.
