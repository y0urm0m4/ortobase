# Дизайн-система

## Цветовая палитра
Тема: **белый + спектр голубого**.

| Назначение         | Имя       | HEX       | Где                           |
| ------------------ | --------- | --------- | ----------------------------- |
| Фон страницы       | white     | `#FFFFFF` | `body`                        |
| Светло-голубой акц.| sky-50    | `#F0F8FF` | секции, hover карточек        |
| Голубой светлый    | sky-200   | `#BEE3F8` | бейджи, фон плиток            |
| Голубой основной   | sky-500   | `#3DA9FC` | кнопки, ссылки, акценты       |
| Глубокий синий     | blue-700  | `#1E5F8E` | заголовки, навбар             |
| Темно-синий        | navy-900  | `#0B2545` | футер, текст h1               |
| Серый текст        | gray-600  | `#5C6B73` | вспомогательный текст         |
| Граница            | gray-200  | `#E5E7EB` | рамки карточек                |

## CSS-переменные (в `style.css`)
```css
:root {
  --color-bg: #FFFFFF;
  --color-sky-50: #F0F8FF;
  --color-sky-200: #BEE3F8;
  --color-sky-500: #3DA9FC;
  --color-blue-700: #1E5F8E;
  --color-navy-900: #0B2545;
  --color-gray-600: #5C6B73;
  --color-gray-200: #E5E7EB;
}
```

## Типографика
- **Шрифт:** `Inter` или `Montserrat` (Google Fonts), запасной `system-ui, sans-serif`
- **H1:** 2.5rem, 700, `--color-navy-900`
- **H2:** 2rem, 600, `--color-blue-700`
- **H3:** 1.25rem, 600
- **Body:** 1rem, 400, `--color-gray-600`

## Компоненты
- **Кнопка primary:** фон `sky-500`, текст белый, скругление 8px, hover — `blue-700`
- **Карточка товара:** белый фон, тень `0 2px 8px rgba(11,37,69,0.08)`, при hover приподнимается `transform: translateY(-4px)`
- **Бейдж размера:** фон `sky-50`, текст `blue-700`, рамка `1px solid sky-200`
- **«Крутое свойство»:** цветной чип с иконкой Bootstrap Icons, фон `sky-200`

## Иконки
[Bootstrap Icons](https://icons.getbootstrap.com/) — подключить через CDN. Примеры:
- `bi-shield-check` — гарантия
- `bi-truck` — доставка
- `bi-heart-pulse` — здоровье
- `bi-award` — сертификация

## Адаптив
Bootstrap-сетка:
- Десктоп: 3–4 карточки в ряд
- Планшет: 2 в ряд
- Телефон: 1 в ряд (кадры наваливаются друг на друга)
